# 📝 Notes App

A full-stack notes application to create, organize, search, and manage your personal notes — fast, simple, and secure.

Built with the MERN stack + Tailwind CSS for real-world CRUD, authentication, and clean UI.

## ✨ Features

- Create, Edit, Delete Notes (Full CRUD)
- Search Notes Instantly
- Pin Important Notes
- User Authentication (Login / Signup)
- Responsive UI for Mobile & Desktop
- Clean & Minimal Design with Tailwind CSS
- Organized Folder Structure - `backend/` + `frontend/`

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, JavaScript, HTML
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT
- **Styling:** Tailwind CSS
- **Tools:** Git, GitHub, VS Code

## 📁 Project Structure


notes_app/
├── backend/ # Express + MongoDB API
├── frontend/ # React + Tailwind CSS App
├── http://package.json
└── http://README.md


## 🚀 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/mayukhmondal42/notes_app.git
cd notes_app

2. Backend Setup

cd backend
npm install
npm run dev

Create `.env` in `backend/`:

MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
PORT=5000

3. Frontend Setup

cd frontend
npm install
npm start

App will run at: `http://localhost:3000`
